# 9RAYA.TN — Git Workflow

## Main Branch

main

The main branch must always contain stable code.

## Feature Branches

Use:

feature/<name>

Examples:

feature/authentication

feature/student-dashboard

feature/library

feature/classroom

## Bug Fixes

Use:

fix/<name>

Example:

fix/login-validation

## Documentation

Use:

docs/<name>

Example:

docs/update-architecture

## Commit Convention

Use Conventional Commits.

Examples:

feat: add student registration

fix: correct login validation

docs: update architecture

refactor: improve resource service

test: add authentication tests

chore: update dependencies

ci: add frontend workflow

## Pull Requests

Every significant feature should be reviewed through a Pull Request.

## Main Rule

Never push unfinished experimental code directly to main.
