# 9RAYA.TN — MVP

## Objective

Lancer une première version fonctionnelle de 9RAYA.TN permettant aux élèves et aux enseignants de créer un compte et d'accéder à une bibliothèque pédagogique organisée.

## MVP — Inclus

### Authentication

- Inscription
- Connexion
- Déconnexion
- Réinitialisation du mot de passe
- Gestion du profil

### Student

- Profil étudiant
- Niveau
- Section
- Gouvernorat
- Établissement
- Tableau de bord

### Teacher

- Profil enseignant
- Matières
- Niveaux
- Sections
- Établissement
- Gouvernorat
- Biographie
- Statut de vérification

### Academic Structure

- Niveaux
- Sections
- Matières
- Gouvernorats
- Établissements

### Library

- Cours
- Résumés
- Exercices
- Devoirs
- Examens
- Baccalauréat
- Corrections
- Vidéos
- Liens externes

### Search

- Recherche globale
- Filtres par niveau
- Filtres par section
- Filtres par matière
- Filtres par type de contenu

### Teacher Content Management

- Ajouter une ressource
- Modifier une ressource
- Supprimer une ressource
- Publier une ressource

## MVP — Exclu temporairement

- Intelligence artificielle avancée
- 9RAYA News Intelligence
- Gamification avancée
- Marketplace
- 9RAYA+
- B2B
- Analytics avancés
- Application mobile native

## Success Criteria

Le MVP est considéré comme fonctionnel lorsqu'un élève peut :

1. Créer un compte.
2. Sélectionner son niveau et sa section.
3. Accéder à sa bibliothèque.
4. Rechercher une ressource.
5. Ouvrir une ressource.

Et lorsqu'un enseignant peut :

1. Créer un compte.
2. Compléter son profil.
3. Être vérifié.
4. Ajouter une ressource.
5. Modifier une ressource.
6. Publier une ressource.
