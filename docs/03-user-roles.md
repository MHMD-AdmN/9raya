# 9RAYA.TN — User Roles

## STUDENT

Un élève inscrit sur la plateforme.

### Peut

- Consulter son profil
- Modifier ses informations personnelles autorisées
- Consulter la bibliothèque
- Rechercher des ressources
- Télécharger ou consulter les ressources autorisées
- Rejoindre un Classroom
- Participer aux discussions
- Répondre aux exercices
- Signaler un contenu

### Ne peut pas

- Publier une ressource pédagogique officielle
- Modifier les ressources d'un enseignant
- Vérifier un enseignant
- Administrer la plateforme

---

## TEACHER

Enseignant inscrit sur la plateforme.

### Peut

- Gérer son profil
- Ajouter des ressources
- Modifier ses propres ressources
- Supprimer ses propres ressources
- Créer des Classrooms
- Publier des devoirs
- Créer des quiz
- Publier des annonces
- Évaluer les travaux des élèves

### Vérification

Le compte possède :

verified = false

avant validation.

Après validation :

verified = true

---

## MODERATOR

Utilisateur chargé de la modération.

### Peut

- Examiner les signalements
- Masquer un contenu
- Supprimer un contenu selon les règles
- Suspendre certains comptes
- Examiner les discussions
- Traiter les abus

---

## ADMIN

Administrateur principal de la plateforme.

### Peut

- Gérer les utilisateurs
- Gérer les enseignants
- Vérifier les enseignants
- Gérer les contenus
- Gérer les établissements
- Gérer les matières
- Gérer les niveaux
- Gérer les sections
- Gérer les modérateurs
- Configurer la plateforme
- Accéder aux statistiques
