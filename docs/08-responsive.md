# 9RAYA.TN — Responsive Design

## Mobile First

Priority:

1. Smartphone
2. Tablet
3. Laptop
4. Desktop

## Minimum supported layout

Mobile:
320px+

Tablet:
768px+

Desktop:
1024px+

Large desktop:
1440px+

## Navigation

Mobile:

- Bottom navigation or compact navigation
- Hamburger menu
- Search prominently accessible

Desktop:

- Sidebar
- Top navigation
- Global search
