# 9RAYA.TN 🇹🇳

> Apprendre. Partager. Progresser.

9RAYA.TN est une plateforme éducative tunisienne destinée aux lycéens et aux enseignants.

## 🎯 Vision

Devenir la plateforme éducative numérique de référence en Tunisie.

## 🚀 Mission

Simplifier l'accès aux ressources éducatives et créer un environnement numérique permettant aux élèves et aux enseignants d'apprendre, de partager et de progresser.

## 📚 Core Features

- 👤 Comptes élèves
- 👨‍🏫 Comptes enseignants
- ✅ Vérification des enseignants
- 📚 Bibliothèque pédagogique
- 🏫 Classrooms
- 👥 Communauté
- 🔎 Recherche avancée
- 📊 Suivi de progression
- 🤖 Outils IA
- 📰 Actualités éducatives
- 🏆 Gamification optionnelle
